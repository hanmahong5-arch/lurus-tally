# 进销存使用说明（种子客户版）

写给店主和店里的伙计。不用懂技术，照着做就行。有问题随时找我们的客服（客服微信/电话：【交付时填写】）。

> 【交付前填写】本文第 3 行和末尾的客服联系方式交付前必须填上，填好后删掉这一行。

## 一、怎么开店

1. 注册一个账号并登录。
2. 第一次进来会让你选店的类型：零售 / 批发、苗木 / 园林、跨境贸易。店的类型不能自己改，选错了请联系客服调整，所以请按你的主要生意选。
3. 系统会放几个示例商品和示例单据，方便你熟悉操作。它们会混进库存和报表里，用熟了就可以清除：首页（左侧菜单「仪表盘」）上方的「清除示例数据」，或账户中心里的「示例数据」都能一键清除；清除只删示例内容，你自己录的货和单据不受影响。也可以一开始就跳过示例，直接录自己的货。
4. 系统已经建好一个仓库，有多个仓库再到「设置」→「仓库」添加。然后录商品、期初库存，就可以开单了。

## 二、一个账号只能属于一个店

- 一个账号同一时间只能在一个店里。老板有自己的店，伙计加入老板的店，用的都是各自的账号。
- 不要用老板的账号让伙计登录，也不要让伙计在加入之前自己先开店。每个人用自己的手机和账号，这样谁做了什么才分得清，收银退货、草稿归属也才对得上。
- 如果伙计已经误开了店：只有示例数据、没有录过真实商品和单据的空店，打开邀请链接时会提示，确认后可以放弃空店并加入老板的店。放弃后空店会停用，不能恢复。已经有真实商品、单据或其他成员的店不能放弃，请换一个没开过店的账号来加入，或联系客服。

## 三、怎么邀请员工（一定用链接）

1. 老板或店长打开左侧菜单「设置」→「团队成员」，点邀请，选好角色，生成邀请链接。
2. 把链接发给对方（微信里发就行）。链接只显示这一次，没复制就重新生成一个。
3. 对方用自己的手机点开链接，注册或登录，再点「加入店铺」就进店了。链接 3 天内有效，只能用一次，发错了可以在团队成员页撤销。
4. 不要自己点自己发出的链接。老板打开自己店的链接会看到「这是你自己店的邀请链接，请发给对方……」，把链接发给对方，让他用自己的账号打开。
5. 角色选错了可以在团队成员页改，也可以把人移出店。老板本人不能被移出。

## 四、各角色能做什么

| 角色 | 能做的事 | 看不到 / 不能做 |
|---|---|---|
| 老板 | 全部：开单、审核、作废、收付款、报表、成本和毛利、团队成员、套餐付费 | 无 |
| 店长 | 除套餐付费和接口密钥外基本和老板一样：审核、看成本毛利、管理团队 | 不能改动老板和其他店长，不能管付费和接口密钥 |
| 店员 | 录商品、盘点、开销售草稿（老板或店长审核后出库）和采购草稿、新建客户和供应商 | 看不到进价、成本、毛利；不能审核、不能作废 |
| 收银 | 在收银台结账、查价、新建客户、办理退货 | 看不到成本；其他页面基本不能用 |
| 财务 | 记收付款、管发票、看报表和成本毛利 | 不能改商品和库存；单据只能看 |

要点：
- 零售店的店员不能在收银台结账，结账请用收银角色。
- 收银只在零售店的收银台使用；苗木店、跨境贸易店请邀请成「店员」，邀请里不会出现「收银」。
- 成本、进价、毛利、采购金额，店员和收银一律看不到，这是有意设计的。

## 五、收银员换班要退出登录

- 共用一台收银机时，换班一定要点右上角的「退出登录」，下一位用自己的账号登录。不要共用一个账号。
- 退出前请先把这台电脑上打开的其他后台页面关掉。系统会让其他页面一起跳回登录页，但最稳妥的做法是先关掉。
- 如果退出没成功（比如断网），系统会提示「退出没有成功」，你仍是登录状态，购物车里没结的东西和还没记的退款提醒都还在，其他页面也不会跳走；网络恢复后再点一次「退出登录」。
- 「今日结单」的入口：先从左侧菜单进「POS 收银」，再点右上角的「今日结单」。每位收银在里面只看到自己收的钱，换班时各自对着点钱；全店合计由老板或店长在「今日结单」里切到「全店」查看，在「全店」下，当天有两个人以上收过钱时，还可以按收银员分别查看。财务看报表，不看今日结单。

## 六、收银退货只退当天、本人开的小票

- 收银员可以在收银台办理退货退款，但只限当天、自己开的小票。
- 昨天的、别人开的小票，系统会提示「请找老板或店长」，由老板或店长来办。

## 七、店员的采购草稿，由老板补价审核

- 店员可以建采购草稿，填商品和数量。单价和金额店员看不到，也不用填。
- 店员在采购单里只能看到自己建的草稿，看不到别人的，也看不到金额。保存后会提示「采购草稿已保存，等老板或店长审核」。
- 老板或店长打开草稿，补上单价，再审核。审核之后才会增加库存。
- 想让店员核对到货，可以让他按草稿上的商品和数量点货。

## 八、新商品先由老板填进价

- 店员可以新建商品，但进价看不到、填不了，新商品一开始没有进价。
- 老板或店长之后给新商品补上进价，成本和毛利才准。
- 在进价补上之前，店员用这个商品盘点时，系统会提示「请老板或店长先填进价」。
- 老板审核采购单时如果单价还是 0，系统会提醒先补价；如果确实是赠品，可以点「确认是赠品，按 0 入账」。

## 九、试用期不限人数

试用期间不限制店里成员的人数，多叫几个伙计也没关系。「订阅」页上只写系统实际执行的限制，没有执行的人数、商品数、仓库数上限不会出现。正式收费的价格和人数规则，等定下来之后会提前告诉你。

## 十、AI 助手试用期不开放

AI 助手在试用期不开放，页面上可能看不到它，这是正常的。所有开单、盘点、查账都用手工操作，不影响使用。

## 十一、系统没有月结

- 系统没有月结、结账封账这一步。每张单据审核后就生效，库存和账实时更新。
- 想看某个月的情况，直接按日期范围看报表。
- 按月看应收时，之后收到的钱会让当时的应收数变少；月底要留底，请当天导出表格保存。
- 单据审核之后如有错，由老板或店长作废后重开；店员和收银不能改已审核的单据。
- 删除的仓库、供应商、苗木、项目在列表里不再显示，要找回请联系客服。

## 十二、收款状态员工看得到

- 能看销售单的人（包括店员和收银）可以在销售单列表里看到每张单的合计、已收、未收（用手机看时列表只显示合计和未收，已收在单据详情里看），在单据详情里看到总金额、已收、应收。这是有意的，方便伙计知道谁还没付钱。店员在「仪表盘」也能看到「今日销售」（全店当天销售额）；零售店的收银打开后台首页会直接进收银台。
- 成本、进价、毛利、采购金额这些员工看不到，仍然只给老板、店长和财务。
- 收银台结账时收的钱会自动记上；事后补记收款只有老板、店长、财务能做。

## 遇到问题

- 看到提示「请找老板或店长」：说明这个操作需要更高权限的人来做。
- 邀请链接打不开或提示失效：链接过期、已被用过或被撤销了，请店主重新发一个。
- 其他问题联系客服（客服微信/电话：【交付时填写】）。
